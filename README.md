# cmk-w26-game-kento
冬キャンプ2026「ゲームづくり」の**基礎検討用**の拡張です（本番用ではありません）。

軸は障害物レース。スタートからゴールまで、ふむと橋が出る・階段・消えたり出たりする床・時間・おじゃまモンスター。
倒したとき・お宝をとったとき を組み合わせると、バトルやお宝集めにも広がります。

- 使うワールド：Aimyゲームづくり箱庭（基礎検討）。ワールド側のスクリプト（w26set）が入っているワールドでだけ動きます
- 場所は色でつなぎます（座標は使いません）：スタート＝エメラルドブロックの上のかんあつばん／ゴール＝金ブロックの上のかんあつばん／〔色〕のスイッチ＝〔色〕のウールの上のかんあつばん／〔色〕のめじるし＝〔色〕の彩釉テラコッタ（置いたときに向いていた方へ橋がのびる）／〔色〕のゆか＝〔色〕のコンクリート
- 「ぶひんを もらう」で、部品がもちものに入ります

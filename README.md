# cmk-w26-game-kento
冬キャンプ2026「ゲームづくり」の**基礎検討用**の拡張です（本番用ではありません）。

- 使うワールド：Aimyゲームづくり箱庭（基礎検討）。ワールド側のスクリプト（w26set）が入っているワールドでだけ動きます
- 分類は4つ：イベント／しかけ／あそぶ人／ゲーム
- 場所は部品で決めます（座標は使いません）：スタート・ゴール・スイッチ・おてつだいロボ・きえるブロック・かぎつきとびら・アウトゆか（チェストは マイクラの物）
- 作った人の MakeCode が操作盤です。遊ぶ人は MakeCode を動かしません
- かぎ：「〔とびら・チェスト〕に さわったとき」に「もし〔アイテム〕を もっていたら ひらく／そうでないなら ひらかない」。持っているかは ワールドが見ます
